I built a small web tool called AI Prompt Builder.

Good AI answers start with a good prompt. This tool turns a simple form
(task, topic, audience, tone, format, word limit) into a structured prompt
using the Role, Task, Context, Format, Constraints framework. You can copy it
or open it directly in ChatGPT or Claude.

- Prompt engineering structure
- JavaScript (DOM, filtering, clipboard)
