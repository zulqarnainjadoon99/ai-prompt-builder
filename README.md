# AI Prompt Builder

A lightweight browser-based tool that turns a short task description into a more structured prompt for AI assistants.

## How It Works

Enter details such as:
- Task or objective
- Topic and context
- Intended audience
- Tone and output format
- Desired word limit or constraints

The tool organizes the information into a structured prompt using a Role, Task, Context, Format, and Constraints approach. Users can copy the result or open it in a supported AI assistant.

## Skills Demonstrated

- Prompt engineering and structured instructions
- JavaScript and DOM interaction
- Form handling and input filtering
- Clipboard interaction
- Static website deployment with GitHub Pages
